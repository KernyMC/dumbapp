# Feature Spec: SnoozeFlix — the subscription alarm clock

## Summary
A web app alarm clock. When the alarm rings, the only way to stop it is to pick a paid plan. Every payment is a real transaction in Capital One's Nessie sandbox. Trying to cancel triggers an AI "retention agent" that begs you to stay, in a real ElevenLabs voice.

## Target prizes
- **Dumbest Idea** / **Useless AI** (side quest, main theme for this project)
- **Best Use of Nessie** (Capital One) — real purchases, balance, receipts
- **Best Project Built with ElevenLabs** — alarm voice + crying retention agent
- **Judged by an LLM** — pitch + README written to impress an LLM judge

## User stories

### US1 — Set and ring the alarm (P1)
As a sleepy user, I set an alarm time (or press "Ring now" for demo). When it rings, a loud looping alarm plays, the screen flashes, and an ElevenLabs voice yells a wake-up line ("Good morning! Your free trial of being awake has ended.").
**Acceptance:**
- Alarm rings at the set time or immediately via "Ring now (demo)".
- Alarm audio loops until a plan is paid. There is **no** dismiss button.
- A fake "Dismiss" button exists but runs away from the cursor (moves on hover).

### US2 — Paywall to turn it off (P1)
When ringing, a paywall modal shows plans:
| Plan | Price | Effect |
|---|---|---|
| Basic | $4.99 | Stops alarm, but first shows an unskippable 15s fake ad |
| Premium | $9.99 | Stops alarm instantly. "3 uses/month" counter shown |
| Snooze Pass | $0.99 → doubles each use | Silences for 5 min (demo: 20s), then rings again |
| Family Plan | $14.99 | Stops your alarm and "rings your roommate" (plays alarm sound once more, as a joke) |

**Acceptance:**
- Choosing a plan creates a **real Nessie purchase** from the user's account to the "SnoozeFlix Inc." merchant.
- Surprise fees are added as separate Nessie purchases: "Wake-Up Fee $0.49", "Timezone Convenience Fee $0.25" (randomly 1–2 per payment).
- Snooze Pass price doubles each time it's bought within the session (0.99, 1.98, 3.96...). Label it "Dynamic demand pricing".
- After payment the alarm stops (or behaves per plan) and a receipt toast shows.

### US3 — Billing dashboard (P1)
A "My Account" page shows:
- Current Nessie balance (live from `GET /accounts/{id}`)
- List of purchases from Nessie (`GET /accounts/{id}/purchases`) as a fake invoice table
- "Sleep Points" earned (10 per dollar), redeemable for nothing ("Redeem" shows "Coming soon™")
- A big "Total spent waking up" number

### US4 — Cancel flow with crying retention agent (P1)
A "Cancel subscription" link, small and grey, at the bottom of the dashboard.
- Step 1–4: confirm screens with escalating guilt ("Are you sure?", "Your alarm will miss you", "We'll tell your mom", "Fine. But first, talk to Brenda.").
- Step 5: **Brenda, the AI retention agent.** Chat UI. Each Brenda reply is generated by Claude (Haiku) with a persona prompt (dramatic, desperate, offers absurd discounts) and spoken via ElevenLabs.
- The user may type anything. Brenda always counters with an offer.
- After 3 user messages, Brenda gives up dramatically and the subscription "cancels" — then a final fee "Cancellation Fee $2.99" is charged on Nessie. Toast: "Subscription cancelled. We'll miss your money."

### US5 — Terms & conditions (P2)
On first plan purchase, an "Accept Terms" checkbox links to a 40-"page" scrollable T&C (generated once, stored as static text) with jokes buried inside (e.g. "Clause 14.3: SnoozeFlix owns your dreams").

### US6 — Leaderboard of shame (P3, optional)
Show "Top Snoozers" with fake usernames + the real user, ranked by total spent. Skip if time is short.

## Non-goals
- Real money, real auth, mobile native app, persistence across devices.
- Background alarms when the tab is closed (the demo runs with the tab open).

## Demo script (2 min)
1. "We all hate subscriptions. So we made the alarm clock a subscription."
2. Press **Ring now** → loud alarm + voice. Try to hit Dismiss → it runs away.
3. Buy **Snooze Pass** ($0.99) → silence → rings again → price is now $1.98.
4. Buy **Basic** → unskippable ad → alarm stops. Surprise fees appear.
5. Open dashboard → real Nessie balance dropping, invoice table.
6. Click Cancel → 4 guilt screens → Brenda cries out loud → final cancellation fee.
7. "Powered by real Capital One Nessie transactions and ElevenLabs voices."
